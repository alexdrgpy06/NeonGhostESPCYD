## 2024-07-03 - Immediate Visual Feedback on Physical Touchscreens
**Learning:** On hardware physical touchscreens, users lack tactile feedback and tend to repeatedly tap buttons if there isn't an immediate visual response indicating the touch was registered.
**Action:** Always provide immediate visual feedback (e.g., momentarily redrawing the button with inverted colors using a short delay, ~50ms) on touch events before executing the button's action.
