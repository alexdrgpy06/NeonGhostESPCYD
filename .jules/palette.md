## 2026-08-25 - Touchscreen Immediate Visual Feedback
**Learning:** Physical touchscreen interfaces without immediate visual feedback lead to user frustration and repeated tapping, as the hardware response can feel sluggish compared to capacitive screens.
**Action:** Implement momentary visual feedback (like inverted colors with a ~50ms delay) for button presses to clearly indicate interaction state before processing the logic.
